# 🎵 Harmony Music Store

Website e-commerce alat musik yang dibangun menggunakan Nuxt 4 dan Tailwind CSS.

## Fitur

- Home
- Produk
- Detail Produk
- Keranjang
- Checkout
- Order Success
- Servis
- Jual Alat Musik
- Responsive Design

## Tech Stack

- Nuxt 4
- Vue 3
- Tailwind CSS

## Instalasi

Clone repository

```bash
git clone https://github.com/username/harmony-music-store.git
```

Masuk ke project

```bash
cd harmony-music-store
```

Install dependency

```bash
pnpm install
```

Menjalankan project

```bash
pnpm dev
```

Build Production

```bash
pnpm build
```
