# 2. CONTRIBUTING.md

Ini penting supaya semua developer mengikuti aturan yang sama.

```md
# Contributing Guide

Terima kasih telah berkontribusi pada Harmony Music Store.

## Branch

Gunakan branch baru.

Contoh

feature/login

feature/profile

fix/cart-bug

refactor/navbar

## Commit Message

Gunakan Conventional Commit.

feat:

fix:

refactor:

style:

docs:

test:

chore:

Contoh

feat: add faq section

fix: resolve cart quantity bug

refactor: simplify product card

docs: update readme

## Pull Request

Pastikan

- Project dapat dijalankan
- Tidak ada error
- Sudah di-test
- Tidak mengubah fitur lain

## Code Style

- Gunakan Composition API
- Gunakan script setup
- Script berada di atas template
- Gunakan Tailwind CSS
- Nama component PascalCase
- Nama composable diawali use
```
